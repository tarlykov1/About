# Digital Atlas Inspired (WordPress theme)

Тема повторяет **информационную архитектуру** корпоративного геопортала (главная, платформа, решения, о проекте, контакты), но содержит:

- уникальный код;
- уникальный текст;
- уникальные визуальные токены (цвета, отступы, типографика).

## Быстрый запуск

1. Скопируйте папку `digitalatlas-inspired` в `wp-content/themes/` вашего WordPress.
2. Активируйте тему в админ-панели.
3. Создайте страницы:
   - Platform (шаблон `Platform`)
   - Solutions (шаблон `Solutions`)
   - About (шаблон `About`)
   - Contact (шаблон `Contact`)
4. В `Настройки → Чтение` выберите статическую главную страницу.
5. Настройте меню для областей `Primary Menu` и `Footer Menu`.

## Заметка

Для продакшна добавьте защиту формы (например, Contact Form 7 + anti-spam), аналитические скрипты и SEO-метатеги.

## Smoke test без WordPress ядра

Для быстрой проверки шаблонов на фатальные ошибки можно запустить:

```bash
php wp-content/themes/digitalatlas-inspired/tests/smoke-test.php
```

Скрипт поднимает минимальные заглушки WP-функций и проверяет рендер всех основных шаблонов.

## Установщик демо-данных

1. Активируйте тему.
2. Перейдите в `Внешний вид → Demo Installer`.
3. Нажмите кнопку **Install demo data**.

Установщик:
- создаёт/обновляет страницы Home, Platform, Solutions, About, Contact;
- назначает шаблоны страниц темы;
- устанавливает статическую главную страницу;
- создаёт demo-меню и привязывает его к `Primary` и `Footer`.

Контент демонстрационный и намеренно изменён относительно референса.
